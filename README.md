# dio-desafio-phishing
##Desafio DIO - Criação de um Phishing com o Kali Linux

### Ferramentas utilizadas
- Kali linux
- ferramenta setoolkit

### Passos para a configuração do Phishing no Kali Linux

- Abrir a CLI
- Habilitar acesso root: ``` sudo su ```
- Iniciar o setoolkit digitando: ``` setoolkit ```
- Selecionar o tipo de ataque: ``` Social-Engineering Attacks ```
- Vetor de ataque: ``` Web Site Attack Vectors ```
- Método de ataque: ```Credential Harvester Attack Method ```
- Método de ataque: ``` Site Cloner ```
- Para obter o endereço da máquina: ``` ifconfig ```
- URL utilizado para clone: http://www.facebook.com
